# Меню

Веб-приложение: меню на 4 недели, закупки, раскладка по морозилке и готовка с рецептами — всё на одной странице недели.

Репозиторий: https://github.com/SashaSosnova/menu

Сайт: https://sashasosnova.github.io/menu/

## Запуск

```bash
npm install
cp .env.example .env   # те же ключи Firebase, что в planer
npm run dev
```

## Облако

Данные (книга рецептов, оценки, галочки закупок и заготовок, журнал остатков) синхронизируются через **Firebase Firestore** — тот же проект, что и planer (`menu` collection).

1. Скопируйте `VITE_FIREBASE_*` из `.env` planer в `.env` menu (или из Firebase Console).
2. Для GitHub Pages добавьте те же переменные в **Settings → Secrets → Actions** репозитория.
3. В приложении нажмите **«облако»** / **«гость»** в шапке → создайте аккаунт или войдите тем же email, что в planer.
4. В Firebase Console добавьте правила для коллекции `menu` (фрагмент в `firestore.rules` в этом репо — вставьте рядом с правилами `planer`).

Без `.env` всё работает локально на устройстве (как раньше).

## Стек

Vite + React + TypeScript + Firebase (Auth + Firestore)

## Что на странице недели

1. **Меню** — обед и ужин с КБЖУ  
2. **Закупка на месяц** (только неделя 1) — мясо/рыба в морозилку  
3. **Как разложить и заморозить** (неделя 1)  
4. **Что купить на неделю** — чеклист (галочки сохраняются)  
5. **Что готовим** — когда и рецепты раскрываются на месте  

Овощи покупаются свежими каждую неделю; замораживать можно только брокколи.

## Синхронизация с planer

Рецепты (ингредиенты, шаги) хранятся здесь. **КБЖУ считаются в planer** и возвращаются в `public/dishes-macros.json`.

| Файл | Кто ведёт | Назначение |
|------|-----------|------------|
| `public/dishes.json` | menu (при сборке) | Экспорт рецептов для импорта в planer |
| `public/dishes-macros.json` | planer | КБЖУ на 100 г для отображения в menu |

**Цикл:**

1. В planer: **Справочник → Menu → Экспорт products-catalog.json** — список названий продуктов.
2. В menu: пишите ингредиенты рецептов теми же названиями.
3. При `npm run build` генерируется `dishes.json` (и попадает на GitHub Pages).
4. В planer: **Справочник → Menu → Загрузить с сайта menu** — разбор ингредиентов и расчёт КБЖУ.
5. В planer: **Экспорт dishes-macros.json** → положите файл в `public/dishes-macros.json` в этом репо и закоммитьте.

Старые КБЖУ из исходников перенесены в `dishes-macros.json` (snapshot). После первого импорта в planer обновите файл из planer.
