# Меню

Веб-приложение: меню на 4 недели, закупки, раскладка по морозилке и готовка с рецептами — всё на одной странице недели.

Репозиторий: https://github.com/SashaSosnova/menu

Сайт: https://sashasosnova.github.io/menu/

## Запуск

```bash
npm install
npm run dev
```

## Что на странице недели

1. **Меню** — обед и ужин с КБЖУ  
2. **Закупка на месяц** (только неделя 1) — мясо/рыба в морозилку  
3. **Как разложить и заморозить** (неделя 1)  
4. **Что купить на неделю** — чеклист (галочки сохраняются)  
5. **Что готовим** — когда и рецепты раскрываются на месте  

Овощи покупаются свежими каждую неделю; замораживать можно только брокколи.

## Стек

Vite + React + TypeScript
